# Emirhan Kütük | Portfolio

Ankara Üniversitesi Bilgisayar Programcılığı öğrencisi olarak projelerimi, öğrenme sürecimi ve sertifikalarımı paylaştığım kişisel portföy sitesi.

**Canlı site:** [emirhankutuk0.github.io](https://emirhankutuk0.github.io/)

## Kullanılan teknolojiler

- HTML5, CSS3 ve vanilla JavaScript
- JetBrains Mono (Google Fonts)
- HTML içine gömülü Simple Icons SVG ikonları
- GitHub Pages ile ücretsiz HTTPS yayını

Framework, npm paketi, backend veya derleme adımı yok. Sayfadaki Stack bölümü kişisel öğrenme alanlarını da gösterir; C# ve PostgreSQL bu sitenin altyapısında kullanılmaz.

## Özellikler

- Koyu terminal teması ve responsive düzen
- Mobil açılır menü ve aktif bölüm takibi
- Projeler, teknoloji kartları ve PDF sertifika bağlantıları
- E-posta ve GitHub iletişim bağlantıları
- EK favicon, klavye odağı ve azaltılmış hareket tercihi desteği

## Yerelde çalıştırma

Depoyu indir veya klonla. Python 3 kuruluysa proje klasöründe şu komutu çalıştır:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Tarayıcıda [http://127.0.0.1:8765](http://127.0.0.1:8765) adresini aç. Sunucuyu durdurmak için terminalde `Ctrl+C` kullan. Python yalnız yerel önizleme içindir; sitenin çalışması için backend gerekmez.

## Dosyalar

- `index.html`: Sayfa içeriği, bağlantılar ve teknoloji ikonları
- `style.css`: Tema ve responsive yerleşim
- `script.js`: Mobil menü, aktif bölüm ve footer yılı
- `favicon.svg`: Sekme simgesi
- `certificates/`: Yayımlanan sertifika PDF'leri

## Yayınlama

GitHub Pages, `main` dalının kök klasöründen yayın yapar. Bu dala gönderilen commit'lerden sonra site otomatik güncellenir. Yayın sonucu deponun **Actions** sekmesinden takip edilebilir.
